# BOOKS VIEW — Google Drive Security

## 1. Mục đích

Tài liệu này quy định cách bảo vệ phần tích hợp Google Drive của BOOKS VIEW.

BOOKS VIEW sử dụng Google Drive API v3 để quét/lấy danh sách ảnh từ folder Drive public. API Key và các thông tin credential nội bộ phải được bảo vệ, không để lộ xuống browser nếu client không cần.

Phạm vi chỉ tập trung vào Google Drive Security của BOOKS VIEW.

---

# 2. Phân biệt API Key và Folder ID

Đây là hai thứ khác nhau.

## Google Drive API Key

Ví dụ:

```text
GOOGLE_DRIVE_API_KEY
```

Đây là credential dùng để server gọi Google Drive API.

Phải coi đây là thông tin nhạy cảm và không expose cho client nếu không cần.

## Google Drive Folder ID

Ví dụ:

```text
1AbCdEfGhIj...
```

Đây chỉ là ID của folder Drive được liên kết với Album.

Folder ID không giống API Key.

Tuy nhiên, cũng không nên trả Folder ID hoặc thông tin Drive nội bộ cho client nếu frontend không thực sự cần.

---

# 3. API Key phải nằm ở Server / Environment Variable

API Key phải được lưu bằng Environment Variable.

Ví dụ:

```env
GOOGLE_DRIVE_API_KEY=AIzaSyxxxxxxxx
```

Code server có thể đọc:

```typescript
process.env.GOOGLE_DRIVE_API_KEY
```

Luồng đúng:

```text
Vercel Environment Variables
        ↓
BOOKS VIEW Server
        ↓
process.env.GOOGLE_DRIVE_API_KEY
        ↓
Google Drive API
```

Browser không cần biết API Key.

---

# 4. Không đặt API Key trong Frontend

Không hard-code:

```typescript
const GOOGLE_DRIVE_API_KEY = "AIzaSy...";
```

trong frontend.

Không đưa API Key vào:

```text
frontend/src/
Client Component
Browser bundle
HTML
JavaScript gửi xuống browser
```

Lý do:

```text
Frontend
   ↓
Build
   ↓
Browser
   ↓
Người dùng có thể inspect
```

Nếu secret được đưa xuống browser, người dùng có khả năng nhìn thấy hoặc trích xuất nó.

---

# 5. Không dùng `NEXT_PUBLIC_*` cho Secret

Không đặt:

```env
NEXT_PUBLIC_GOOGLE_DRIVE_API_KEY=...
```

cho API Key.

Quy tắc:

```text
GOOGLE_DRIVE_API_KEY
```

→ server-side secret.

Không:

```text
NEXT_PUBLIC_GOOGLE_DRIVE_API_KEY
```

nếu giá trị đó cần được giữ bí mật.

`NEXT_PUBLIC_*` nên được hiểu là dữ liệu có khả năng được đưa tới client/browser.

---

# 6. Không đặt Secret trong `public/`

Không đặt:

```text
frontend/public/google-drive-key.txt
```

hoặc:

```text
frontend/public/config.json
```

có chứa:

```json
{
  "GOOGLE_DRIVE_API_KEY": "AIzaSy..."
}
```

Thư mục `public/` chứa tài nguyên có thể được truy cập từ web.

Không lưu credential/secret trong đó.

---

# 7. Không commit Secret lên GitHub

Không commit:

```text
.env
.env.local
```

nếu có secret thật.

`.gitignore` phải có các file environment phù hợp, ví dụ:

```gitignore
.env
.env.local
.env.*.local
```

Không đưa:

```text
GOOGLE_DRIVE_API_KEY
DATABASE_URL
GOOGLE_CLIENT_SECRET
AUTH_SECRET
```

vào source code public hoặc GitHub.

Nếu API key đã từng bị commit public, phải coi key đó có khả năng đã bị lộ và thực hiện rotation/revoke theo cấu hình Google Cloud.

# 11. Ví dụ API Sync Drive

Admin bấm:

```text
Đồng bộ ảnh
```

Browser gọi:

```text
POST /api/albums/123/sync-drive
```

Server thực hiện:

```text
Request
   ↓
Kiểm tra Admin Session
   ↓
Kiểm tra Authorization
   ↓
Lấy Album 123
   ↓
Lấy Album.googleDriveFolderId
   ↓
Lấy process.env.GOOGLE_DRIVE_API_KEY
   ↓
Google Drive API
   ↓
Scan folder
   ↓
Dedup bằng googleDriveId
   ↓
Thêm ảnh mới
   ↓
Response
```

Browser không cần gửi:

```text
GOOGLE_DRIVE_API_KEY
```

và server cũng không cần trả API Key về client.

---

# 12. Google Drive Folder ID

BOOKS VIEW hiện có:

```text
Album.googleDriveFolderId
```

Folder ID được dùng để biết Album đang liên kết với folder Drive nào.

Ví dụ:

```text
Album A
 └── googleDriveFolderId
       ↓
Google Drive Folder A
```

Khi bấm:

```text
Đồng bộ ảnh
```

server dùng Folder ID để xác định đúng folder.

---

# 13. Không expose Drive Information nếu Client không cần

Ví dụ client chỉ cần biết:

```json
{
  "success": true,
  "newPhotos": 25
}
```

thì không cần trả:

```json
{
  "googleDriveApiKey": "...",
  "googleDriveFolderId": "...",
  "internalDriveConfig": "..."
}
```

Nguyên tắc:

> **Chỉ trả dữ liệu Google Drive mà frontend thực sự cần.**

---

# 14. Public Folder không có nghĩa API Key được public

BOOKS VIEW sử dụng folder Drive có thể được chia sẻ:

```text
Anyone with the link
```

Điều này không có nghĩa:

```text
Google Drive API Key
```

cũng phải public.

Phải phân biệt:

```text
Public Drive Folder
        ≠
Public API Credential
```

Folder có thể public trong khi API Key vẫn phải được bảo vệ ở server.

---

# 15. Restrict API Key

Nếu cấu hình Google Cloud cho phép, nên giới hạn API Key theo:

- API/service cần sử dụng.
- Các restriction phù hợp với cách BOOKS VIEW gọi Google API.

Mục tiêu là nếu key bị lộ thì phạm vi sử dụng vẫn bị hạn chế.

Không nên cấp quyền rộng hơn nhu cầu thực tế.

---

# 16. Nếu API Key bị lộ

Không coi việc folder là public là lý do để bỏ qua API Key security.

API Key bị lộ có thể dẫn đến:

- Người khác sử dụng quota.
- API abuse.
- Khó kiểm soát nguồn request.
- Quota bị tiêu hao.
- Khó phân biệt traffic hợp lệ của BOOKS VIEW.

Nếu nghi ngờ key bị lộ:

```text
Phát hiện key bị lộ
        ↓
Restrict / Revoke / Rotate key
        ↓
Tạo key mới nếu cần
        ↓
Cập nhật Vercel Environment Variables
        ↓
Redeploy
        ↓
Kiểm tra lại Google Drive API
```

---

# 17. Server-only Google Drive Logic

File logic Google Drive hiện tại của BOOKS VIEW:

```text
frontend/src/lib/google-drive.ts
```

nếu trực tiếp sử dụng:

```text
GOOGLE_DRIVE_API_KEY
```

thì phải đảm bảo logic đó không bị import vào Client Component theo cách làm secret xuất hiện trong browser bundle.

Nguyên tắc:

```text
Google Drive Credential
        ↓
Server-only code
        ↓
Google Drive API
```

Không:

```text
Google Drive Credential
        ↓
Client Component
        ↓
Browser
```


Server đã có:


# 20. Google Drive Sync và dữ liệu Photo

Sync Drive của BOOKS VIEW phải giữ nguyên nguyên tắc hiện tại:

```text

 ↓
Scan
```

```text

 ↓

 ↓

```

# 21. Không trả lỗi Google API trực tiếp cho Client

Nếu Google Drive API lỗi, không trả nguyên lỗi nội bộ cho browser.

Không nên trả:

```text
Google API error...
API key configuration...
internal request details...
server stack trace...
```

Nên trả message an toàn:

```json
{
  "success": false,
  "error": {
    "code": "DRIVE_SYNC_FAILED",
    "message": "Không thể đồng bộ Google Drive. Vui lòng thử lại."
  }
}
```

Chi tiết kỹ thuật nằm trong server log.

---

# 22. Logging

Có thể log:

```text
albumId
requestId
timestamp
sync status
number of new photos
number of skipped photos
Google API error category
```

Không log:

```text
GOOGLE_DRIVE_API_KEY
DATABASE_URL
GOOGLE_CLIENT_SECRET
AUTH_SECRET
session token
```

Nếu log Google API error, cần tránh ghi credential hoặc dữ liệu nhạy cảm.

# 23. Security Checklist

```text
□ GOOGLE_DRIVE_API_KEY nằm trong Environment Variable
□ Không hard-code API Key
□ Không dùng NEXT_PUBLIC_ cho API Key
□ Không đặt API Key trong public/
□ Không commit API Key lên GitHub
□ Không trả API Key trong API response
□ Google Drive logic sử dụng secret chạy server-side
□ Client không trực tiếp nhận credential
□ Sync Drive API có Authentication
□ Sync Drive API có Authorization
□ Album được kiểm tra quyền trước khi sync
□ Server lấy googleDriveFolderId từ database khi phù hợp
□ Không tin credential/Folder ID do client gửi nếu server đã có dữ liệu
□ Chỉ trả dữ liệu Drive cần thiết
□ Không trả Google API error nội bộ
□ Không trả stack trace production
□ Không log API Key
□ API Key được restrict nếu có thể
□ Có quy trình rotate/revoke khi key bị lộ
□ Sync không tự ý xóa Photo cũ
□ Dedup ưu tiên googleDriveId
```

```text
✓ Không expose database/config nội bộ

```

# Nguyên tắc cuối cùng

> **Google Drive API Key là chìa khóa của server, không phải dữ liệu của browser.**

> **Google Drive Folder ID chỉ là địa chỉ của folder; không được nhầm nó với credential.**

Kiến trúc mục tiêu:

```text
Browser
   ↓
BOOKS VIEW API
   ↓
Authentication
   ↓
Authorization
   ↓
Server
   ↓
GOOGLE_DRIVE_API_KEY
   ↓
Google Drive API
   ↓
Drive Folder
   ↓
Photos
```

Browser chỉ nhận kết quả cần thiết từ BOOKS VIEW, không nhận credential nội bộ.
