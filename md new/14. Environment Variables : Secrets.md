# BOOKS VIEW — Environment Variables / Secrets

## 1. Mục đích

Tài liệu này quy định cách quản lý Environment Variables và Secrets cho BOOKS VIEW.

Mục tiêu:

- Không để secret trong source code.
- Không commit secret lên GitHub.
- Không đưa secret xuống frontend/browser.
- Không dùng `NEXT_PUBLIC_*` cho secret.
- Có thể chuyển BOOKS VIEW giữa Vercel, VPS hoặc hosting khác mà không phải thay đổi kiến trúc bảo mật.
- Tách source code, configuration và secret.

---

# 2. Environment Variables là gì?

Environment Variables là các biến cấu hình được cung cấp cho server/runtime của BOOKS VIEW.

Ví dụ:

```text
DATABASE_URL
GOOGLE_DRIVE_API_KEY
GOOGLE_CLIENT_SECRET
AUTH_SECRET
OAUTH_SECRET
```

Có thể hình dung:

```text
BOOKS VIEW
    │
    ├── Source Code
    │
    └── Environment Variables
            ├── DATABASE_URL
            ├── GOOGLE_DRIVE_API_KEY
            ├── GOOGLE_CLIENT_SECRET
            ├── AUTH_SECRET
            └── OAUTH_SECRET
```

Source code chỉ tham chiếu đến biến:

```typescript
process.env.DATABASE_URL
```

thay vì ghi trực tiếp credential vào code.

---

# 3. Các Secret quan trọng của BOOKS VIEW

## 3.1. DATABASE_URL

Dùng để kết nối PostgreSQL.

Ví dụ:

```env
DATABASE_URL="postgresql://username:password@host:5432/booksview"
```

Có thể chứa:

- Database host.
- Username.
- Password.
- Database name.
- Connection information.

Phải giữ ở server.

Không đưa xuống frontend.

---

## 3.2. GOOGLE_DRIVE_API_KEY

Dùng để server gọi Google Drive API.

```env
GOOGLE_DRIVE_API_KEY="AIzaSy..."
```

Phải được bảo vệ.

Không:

```text
Client Component
public/
Browser bundle
NEXT_PUBLIC_*
GitHub source
API response
```

---

## 3.3. GOOGLE_CLIENT_SECRET

Dùng trong Google OAuth của Studio/Admin.

Ví dụ:

```env
GOOGLE_CLIENT_SECRET="..."
```

Phải ở server.

Không đưa vào browser.

---

## 3.4. AUTH_SECRET

Secret phục vụ authentication/session/security flow của ứng dụng tùy kiến trúc hiện tại.

Ví dụ:

```env
AUTH_SECRET="random-long-secret"
```

Phải giữ kín.

---

## 3.5. OAUTH_SECRET

Nếu BOOKS VIEW sử dụng secret riêng cho OAuth/session flow:

```env
OAUTH_SECRET="..."
```

cũng phải được bảo vệ như secret.

---

# 4. Không hard-code Secret trong Source Code

Không làm:

```typescript
const GOOGLE_DRIVE_API_KEY = "AIzaSy...";
```

Không làm:

```typescript
const AUTH_SECRET = "abc123";
```

Không làm:

```typescript
const DATABASE_URL = "postgresql://...";
```

Đúng:

```typescript
const apiKey = process.env.GOOGLE_DRIVE_API_KEY;
```

```typescript
const databaseUrl = process.env.DATABASE_URL;
```

Mục tiêu:

```text
Source Code
    ↓
process.env
    ↓
Environment
```

---

# 5. Không đưa Secret vào Frontend

Frontend chạy trên máy người dùng:

```text
Next.js
   ↓
Build
   ↓
JavaScript
   ↓
Browser
```

Nếu secret được đưa vào frontend bundle, người dùng có thể inspect:

```text
DevTools
Sources
Network
JavaScript bundle
```

và có khả năng nhìn thấy secret.

Vì vậy các secret phải nằm ở server.

# 6. Không dùng `NEXT_PUBLIC_*` cho Secret

Không:

```env
NEXT_PUBLIC_DATABASE_URL=...
```

Không:

```env
NEXT_PUBLIC_GOOGLE_DRIVE_API_KEY=...
```

Không:

```env
NEXT_PUBLIC_GOOGLE_CLIENT_SECRET=...
```

Không:

```env
NEXT_PUBLIC_AUTH_SECRET=...
```

Quy tắc:

```text
SECRET
    ↓
Không dùng NEXT_PUBLIC_*
```

`NEXT_PUBLIC_*` chỉ nên dùng cho dữ liệu thực sự có thể công khai ở browser.

Ví dụ một cấu hình public:

```env
NEXT_PUBLIC_APP_NAME="BOOKS VIEW"
```

có thể phù hợp nếu không chứa thông tin nhạy cảm.

---

# 7. Không đặt Secret trong `public/`

Không tạo:

```text
frontend/public/google-drive-key.txt
```

Không tạo:

```text
frontend/public/config.json
```

có chứa secret.

Thư mục:

```text
public/
```

được dùng cho tài nguyên public.

Nguyên tắc:

```text
public/
    ↓
Browser có thể truy cập
    ↓
Không chứa Secret
```

---

# 8. Không commit Secret lên GitHub

Không commit:

```text
.env
.env.local
```

nếu chứa secret thật.

Không commit source có:

```text
DATABASE_URL="..."
GOOGLE_DRIVE_API_KEY="..."
GOOGLE_CLIENT_SECRET="..."
AUTH_SECRET="..."
OAUTH_SECRET="..."
```

GitHub dùng để lưu source code, không phải nơi lưu production secrets.

---

# 9. `.gitignore`

Nên có:

```gitignore
.env
.env.local
.env.*.local
```

Mục tiêu:

```text
.env.local
     ↓
.gitignore
     ↓
Git bỏ qua
     ↓
Không push GitHub
```

---

# 10. Nếu Secret đã từng commit lên GitHub

Chỉ xóa dòng secret trong commit mới là chưa đủ.

Secret có thể vẫn nằm trong:

```text
Git history
```

Nếu một secret thật đã từng bị public:

```text
Secret bị lộ
    ↓
Rotate / Revoke
    ↓
Tạo secret mới
    ↓
Cập nhật Environment Variables
    ↓
Redeploy
```

Đặc biệt với:

```text
GOOGLE_DRIVE_API_KEY
GOOGLE_CLIENT_SECRET
AUTH_SECRET
DATABASE credentials
```

phải coi việc public secret là sự cố bảo mật và xử lý credential tương ứng.

# 12. `.env.example`


Ví dụ:

# 14. Chuyển từ Vercel A sang Vercel B

Environment Variables của Vercel A không nên được coi là tự động xuất hiện ở Vercel B.

Khi tạo project mới:

```text
Vercel A
   ↓
Environment Variables
   ↓
Danh sách biến cần dùng
   ↓
Vercel B
   ↓
Nhập các biến tương ứng
```

Ví dụ:

```text
DATABASE_URL
GOOGLE_DRIVE_API_KEY
GOOGLE_CLIENT_SECRET
AUTH_SECRET
OAUTH_SECRET
```

GitHub source vẫn có thể giữ nguyên.

# 18. Environment Variables không phải Database

Cần phân biệt:

```text
DATABASE_URL
```

với:

```text
PostgreSQL Database
```

`DATABASE_URL` chỉ là thông tin để app biết cách kết nối.

Database thật có thể nằm ở:

```text

```

Khi đổi database, cần xử lý:

- Database migration.
- Backup.
- Restore.
- Connection string.

Không bao giờ làm:

```typescript
return Response.json(process.env);
```

Không làm:

```typescript
return Response.json({
  database: process.env.DATABASE_URL
});
```

Không trả:

```text
DATABASE_URL
GOOGLE_DRIVE_API_KEY
GOOGLE_CLIENT_SECRET

OAUTH_SECRET
```

cho browser.

# 23. Logging

Không log secret:

```text
console.log(process.env.DATABASE_URL)
console.log(process.env.GOOGLE_DRIVE_API_KEY)
console.log(process.env.AUTH_SECRET)
```

Không ghi secret vào production logs.

Nếu debug cần kiểm tra cấu hình, chỉ kiểm tra secret có tồn tại hay không, không in giá trị thật.

Ví dụ khái niệm:

```text
GOOGLE_DRIVE_API_KEY configured: true
```

thay vì:

```text
GOOGLE_DRIVE_API_KEY = AIzaSy...
```

# 26. Public Configuration vs Secret

Không phải Environment Variable nào cũng là secret.

## Secret

```text
DATABASE_URL
GOOGLE_DRIVE_API_KEY
GOOGLE_CLIENT_SECRET
AUTH_SECRET
OAUTH_SECRET
```

→ Server only.

## Public configuration

Ví dụ:

```text
NEXT_PUBLIC_APP_NAME
NEXT_PUBLIC_SITE_URL
```

→ Có thể public nếu giá trị thực sự không nhạy cảm.

Nguyên tắc:

> **Có chữ NEXT_PUBLIC không có nghĩa là an toàn cho secret.**

# 29. Nguyên tắc cuối cùng

> **Code có thể đưa lên GitHub. Secret thì không.**

> **Environment Variables không thuộc riêng Vercel.**

> **BOOKS VIEW phải đọc configuration thông qua `process.env` và không được phụ thuộc vào nơi hosting lưu secret.**

Kiến trúc mục tiêu:

```text
GitHub
   │
   │ Source Code
   ↓
Hosting
   │
   ├── Environment Variables 🔒
   │      ├── DATABASE_URL
   │      ├── GOOGLE_DRIVE_API_KEY
   │      ├── GOOGLE_CLIENT_SECRET
   │      ├── AUTH_SECRET
   │      └── OAUTH_SECRET
   │
   └── BOOKS VIEW Server
             │
             ├── PostgreSQL
             ├── Google Drive
             └── Google OAuth
```

Khi đổi:

```text
Vercel → VPS → Docker → Hosting khác
```

chỉ cần cung cấp lại các Environment Variables phù hợp cho môi trường mới. Source code của BOOKS VIEW vẫn có thể giữ nguyên.
