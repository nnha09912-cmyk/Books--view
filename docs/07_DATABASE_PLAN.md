# 07 — Database Plan\n\nPostgreSQL schema for Books View.\n\n**ORM:** Prisma\n\n---\n\n## Tables\n\n### 1. **studios** (Studio accounts)\n\n```sql\nCREATE TABLE studios (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  name VARCHAR(255) NOT NULL,\n  slug VARCHAR(255) UNIQUE NOT NULL,\n  email VARCHAR(255) UNIQUE NOT NULL,\n  password_hash VARCHAR(255) NOT NULL,\n  logo_url VARCHAR(500),\n  description TEXT,\n  phone VARCHAR(20),\n  website VARCHAR(500),\n  api_key VARCHAR(255) UNIQUE,\n  is_active BOOLEAN DEFAULT true,\n  google_drive_token JSONB, -- Encrypted\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n### 2. **albums** (Photo albums)\n\n```sql\nCREATE TABLE albums (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  studio_id UUID NOT NULL REFERENCES studios(id) ON DELETE CASCADE,\n  name VARCHAR(255) NOT NULL,\n  description TEXT,\n  slug VARCHAR(255),\n  template VARCHAR(50) DEFAULT 'classic', -- classic, wedding, etc.\n  link_token VARCHAR(255) UNIQUE NOT NULL, -- Public link identifier\n  password_hash VARCHAR(255), -- If password protected\n  status VARCHAR(50) DEFAULT 'active', -- active, archived, expired\n  expiry_date TIMESTAMP,\n  photo_count INT DEFAULT 0,\n  google_drive_folder_id VARCHAR(255), -- For sync\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n### 3. **photos** (Individual photos)\n\n```sql\nCREATE TABLE photos (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  album_id UUID NOT NULL REFERENCES albums(id) ON DELETE CASCADE,\n  folder_id UUID REFERENCES folders(id) ON DELETE SET NULL, -- If nested\n  filename VARCHAR(255) NOT NULL,\n  original_url VARCHAR(500) NOT NULL, -- Google Drive or storage\n  thumbnail_url VARCHAR(500), -- Optimized thumbnail\n  preview_url VARCHAR(500), -- Medium size\n  width INT,\n  height INT,\n  file_size INT, -- Bytes\n  mime_type VARCHAR(50),\n  like_count INT DEFAULT 0,\n  star_count INT DEFAULT 0,\n  order_index INT, -- Sort order\n  google_drive_id VARCHAR(255), -- For sync\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n### 4. **folders** (Album subfolders)\n\n```sql\nCREATE TABLE folders (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  album_id UUID NOT NULL REFERENCES albums(id) ON DELETE CASCADE,\n  parent_folder_id UUID REFERENCES folders(id) ON DELETE CASCADE, -- Nested\n  name VARCHAR(255) NOT NULL,\n  description TEXT,\n  order_index INT,\n  google_drive_folder_id VARCHAR(255),\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n### 5. **customers** (Khách hàng)\n\n```sql\nCREATE TABLE customers (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  album_id UUID NOT NULL REFERENCES albums(id) ON DELETE CASCADE,\n  name VARCHAR(255) NOT NULL,\n  email VARCHAR(255),\n  phone VARCHAR(20),\n  guest_token VARCHAR(255) UNIQUE, -- For revisiting without email\n  last_viewed_at TIMESTAMP,\n  submitted_at TIMESTAMP, -- When they finalized selections\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW(),\n  UNIQUE(album_id, email) -- One customer per album per email\n);\n```\n\n### 6. **selections** (Customer photo selections)\n\n```sql\nCREATE TABLE selections (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  customer_id UUID NOT NULL REFERENCES customers(id) ON DELETE CASCADE,\n  photo_id UUID NOT NULL REFERENCES photos(id) ON DELETE CASCADE,\n  like_type VARCHAR(50) NOT NULL, -- 'like' (♥) or 'star' (⭐)\n  created_at TIMESTAMP DEFAULT NOW(),\n  UNIQUE(customer_id, photo_id, like_type) -- Prevent duplicates\n);\n```\n\n### 7. **comments** (Future: Customer comments on photos)\n\n```sql\nCREATE TABLE comments (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  photo_id UUID NOT NULL REFERENCES photos(id) ON DELETE CASCADE,\n  customer_id UUID NOT NULL REFERENCES customers(id) ON DELETE CASCADE,\n  text TEXT NOT NULL,\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n### 8. **permissions** (Access control)\n\n```sql\nCREATE TABLE permissions (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  studio_id UUID NOT NULL REFERENCES studios(id) ON DELETE CASCADE,\n  resource_type VARCHAR(50) NOT NULL, -- 'album', 'api', etc.\n  resource_id UUID,\n  action VARCHAR(50) NOT NULL, -- 'read', 'write', 'delete'\n  created_at TIMESTAMP DEFAULT NOW()\n);\n```\n\n---\n\n## Relationships (ERD)\n\n```\nstudios (1) ──→ (N) albums\nalbums (1) ──→ (N) folders\nalbums (1) ──→ (N) photos\nalbums (1) ──→ (N) customers\nfolders (1) ──→ (N) photos (folder_id)\nfolders (1) ──→ (N) folders (parent_folder_id) -- Self-referencing\ncustomers (1) ──→ (N) selections\nphotos (1) ──→ (N) selections\nphotos (1) ──→ (N) comments\ncustomers (1) ──→ (N) comments\n```\n\n---\n\n## Indexes\n\n```sql\n-- Performance\nCREATE INDEX idx_albums_studio_id ON albums(studio_id);\nCREATE INDEX idx_albums_link_token ON albums(link_token);\nCREATE INDEX idx_photos_album_id ON photos(album_id);\nCREATE INDEX idx_photos_folder_id ON photos(folder_id);\nCREATE INDEX idx_customers_album_id ON customers(album_id);\nCREATE INDEX idx_selections_customer_id ON selections(customer_id);\nCREATE INDEX idx_selections_photo_id ON selections(photo_id);\n```\n\n---\n\n## Constraints\n\n- **Foreign Keys:** Cascading deletes for data integrity\n- **Unique:** `link_token`, `api_key`, album `slug` per studio\n- **NOT NULL:** All required fields\n- **Check:** `status` in specific values\n\n---\n\n## Data Lifecycle\n\n### Album Creation\n1. Studio creates album → `albums` row\n2. Photos sync from Drive → `photos` rows\n3. If nested folders → `folders` rows\n4. Generate unique `link_token` → Share with customer\n\n### Customer Viewing\n1. Customer clicks link → Create `customers` row (if first time)\n2. Customer browses photos → Update `last_viewed_at`\n3. Customer likes/stars photos → Create `selections` rows\n4. Customer submits → Update `submitted_at`\n\n### Analytics\n1. Count likes/stars per photo\n2. List customers and their selections\n3. Export as CSV/JSON\n\n---\n\n## Data Retention\n\n- **Active albums:** Keep indefinitely\n- **Archived albums:** Keep 6 months (then offer hard delete)\n- **Customer selections:** Keep with album (cascade delete)\n- **Google Drive sync:** Periodic refresh (daily, if connected)\n\n---\n\n## Security\n\n- **Passwords:** Bcrypt hash (never plain text)\n- **API keys:** Hashed, rotate-able\n- **Google Drive token:** Encrypted at rest\n- **Customer data:** Minimal PII (name, email)\n- **Access control:** Row-level security (studio can only see own data)\n\n---\n\n## Prisma Schema\n\n```prisma\n// prisma/schema.prisma\n\ngenerator client {\n  provider = \"prisma-client-js\"\n}\n\ndatasource db {\n  provider = \"postgresql\"\n  url      = env(\"DATABASE_URL\")\n}\n\nmodel Studio {\n  id               String   @id @default(dbgenerated(\"gen_random_uuid()\")) @db.Uuid\n  name             String\n  slug             String   @unique\n  email            String   @unique\n  passwordHash     String\n  logoUrl          String?\n  description      String?\n  phone            String?\n  website          String?\n  apiKey           String?  @unique\n  isActive         Boolean  @default(true)\n  googleDriveToken Json?\n  createdAt        DateTime @default(now())\n  updatedAt        DateTime @updatedAt\n\n  albums      Album[]\n  permissions Permission[]\n}\n\nmodel Album {\n  id              String   @id @default(dbgenerated(\"gen_random_uuid()\")) @db.Uuid\n  studioId        String   @db.Uuid\n  name            String\n  description     String?\n  slug            String?\n  template        String   @default(\"classic\")\n  linkToken       String   @unique\n  passwordHash    String?\n  status          String   @default(\"active\")\n  expiryDate      DateTime?\n  photoCount      Int      @default(0)\n  googleDriveFolderId String?\n  createdAt       DateTime @default(now())\n  updatedAt       DateTime @updatedAt\n\n  studio      Studio @relation(fields: [studioId], references: [id], onDelete: Cascade)\n  folders     Folder[]\n  photos      Photo[]\n  customers   Customer[]\n\n  @@index([studioId])\n  @@index([linkToken])\n}\n\n// ... (continue with other models)\n```\n\n---\n\n## Future Enhancements\n\n- Audit logs (track changes)\n- Soft deletes (for recovery)\n- Watermark metadata (per album)\n- Analytics tables (materialized views)\n
