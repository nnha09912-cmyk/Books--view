# 09 — Tech Stack\n\n**Books View** built with modern, battle-tested technologies.\n\n---\n\n## Frontend\n\n### Runtime & Build\n- **Next.js 14+** — React framework (App Router, SSR)\n- **React 18+** — UI library\n- **TypeScript** — Type safety\n- **Tailwind CSS** — Utility-first CSS\n- **shadcn/ui** — Component library (built on Radix UI)\n\n### State & Data\n- **TanStack Query (React Query)** — Server state management\n- **Zustand** — Client state (optional, lightweight)\n- **Axios** — HTTP client\n\n### Images & Media\n- **Next.js Image** — Optimized image loading\n- **sharp** — Image processing (on server)\n- **react-medium-image-zoom** — Zoom/lightbox\n\n### Forms & Validation\n- **React Hook Form** — Form state management\n- **Zod** — Schema validation (TypeScript-first)\n\n### Dev Tools\n- **ESLint** — Linting\n- **Prettier** — Code formatting\n- **Storybook** — Component development\n- **Vitest** — Unit tests\n- **Playwright** — E2E tests\n\n---\n\n## Backend\n\n### Runtime & Framework\n- **Node.js 18+** — JavaScript runtime\n- **Express.js** or **Next.js API Routes** — REST API\n- **TypeScript** — Type safety\n\n### Database\n- **PostgreSQL 14+** — Relational database\n- **Prisma** — ORM (type-safe, migrations)\n- **Redis** — Caching, sessions (optional)\n\n### Authentication & Security\n- **jsonwebtoken (JWT)** — Token-based auth\n- **bcryptjs** — Password hashing\n- **dotenv** — Environment variables\n- **helmet** — HTTP headers security\n- **express-rate-limit** — Rate limiting\n\n### File & Cloud Storage\n- **Google Drive API** — Photo sync\n- **sharp** — Image processing\n- **multer** — File upload handling\n- **AWS S3** or **Cloudinary** — Image CDN/storage (optional)\n\n### Validation & Parsing\n- **Zod** — Schema validation (shared with frontend)\n- **joi** or **express-validator** — Request validation\n\n### APIs & Integrations\n- **googleapis** — Google Drive SDK\n- **nodemailer** — Email sending\n- **stripe** (future) — Payment processing\n\n### Dev & Testing\n- **Jest** — Unit tests\n- **Supertest** — API testing\n- **Docker** — Containerization\n- **Nodemon** — Dev server auto-reload\n\n---\n\n## Database\n\n### PostgreSQL\n- Version: 14+\n- Client: Prisma ORM\n- Hosted: AWS RDS, Supabase, or self-hosted\n\n### Schema\n- See `07_DATABASE_PLAN.md`\n- Migrations managed by Prisma\n\n### Caching (Optional)\n- **Redis** — Cache API responses, sessions\n\n---\n\n## Deployment\n\n### Frontend\n- **Vercel** (recommended for Next.js)\n- **Netlify** (alternative)\n- **AWS CloudFront + S3** (self-hosted)\n\n### Backend\n- **Vercel** (Next.js API routes)\n- **AWS EC2** or **ECS** (self-hosted)\n- **Railway** or **Render** (simple hosting)\n- **Docker** container for scalability\n\n### Database\n- **AWS RDS PostgreSQL**\n- **Supabase** (PostgreSQL + Auth + Storage)\n- **DigitalOcean Managed Database**\n\n### CDN & Images\n- **Cloudflare** — CDN, DNS, SSL\n- **CloudFlare Images** or **AWS CloudFront** — Image optimization\n- **Google Cloud Storage** — Raw photo storage\n\n---\n\n## Development Workflow\n\n### Local Development\n```bash\n# Frontend\nnpm run dev          # Start dev server (Next.js)\nnpm run build        # Production build\nnpm run lint         # Linting\nnpm run type-check   # TypeScript check\nnpm run test         # Unit tests\nnpm run e2e          # E2E tests\n\n# Backend (if separate)\nnode --watch index.ts  # Dev server\nnpm run build          # Compile TS\nnpm test              # Tests\n\n# Database\nnpx prisma migrate dev --name \"feature name\"  # Create migration\nnpx prisma db push                             # Apply migrations\nnpx prisma studio                              # DB browser UI\n```\n\n### Git & CI/CD\n- **GitHub** — Version control\n- **GitHub Actions** — CI/CD pipeline\n  - Lint, type-check, test on PR\n  - Auto-deploy to staging on merge to dev\n  - Manual deploy to production\n- **Pre-commit hooks** — Prettier, ESLint\n\n---\n\n## Environment Variables\n\n### Frontend (.env.local)\n```\nNEXT_PUBLIC_API_URL=http://localhost:3000/api (dev) or https://api.books-view.com (prod)\nNEXT_PUBLIC_GOOGLE_CLIENT_ID=...\n```\n\n### Backend (.env)\n```\nNODE_ENV=development|production\nDATABASE_URL=postgresql://user:pass@host:5432/booksview\nJWT_SECRET=...\nJWT_EXPIRES_IN=7d\nGOOGLE_CLIENT_ID=...\nGOOGLE_CLIENT_SECRET=...\nGOOGLE_REDIRECT_URI=...\nSMTP_HOST=...\nSMTP_PORT=...\nSMTP_USER=...\nSMTP_PASS=...\n```\n\n---\n\n## Performance Targets\n\n- **First Contentful Paint (FCP):** < 1.5s\n- **Largest Contentful Paint (LCP):** < 2.5s\n- **Cumulative Layout Shift (CLS):** < 0.1\n- **Time to Interactive (TTI):** < 3s\n- **Page load:** < 2s (with 3G)\n\n### Optimization Strategies\n- Image lazy loading\n- Code splitting (Next.js automatic)\n- API response caching\n- Database query optimization\n- CDN for static assets\n\n---\n\n## Browser Support\n\n- **Desktop:** Chrome, Firefox, Safari (latest 2 versions)\n- **Mobile:** iOS Safari 14+, Chrome Android 90+\n- **Responsive:** 320px (mobile) to 4K\n\n---\n\n## Accessibility (WCAG 2.1 AA)\n\n- Semantic HTML\n- ARIA labels\n- Keyboard navigation\n- Color contrast (4.5:1 minimum)\n- Focus management\n- Screen reader support\n\n---\n\n## Security\n\n- **HTTPS/TLS** — All connections encrypted\n- **JWT** — Stateless authentication\n- **CORS** — Cross-origin protection\n- **Rate limiting** — Prevent brute force/abuse\n- **Input validation** — Zod schemas\n- **SQL injection prevention** — Prisma parameterized queries\n- **XSS prevention** — Next.js sanitization\n- **CSRF tokens** — Optional (not needed with JWT)\n- **Content Security Policy (CSP)** — Prevent inline scripts\n- **Helmet.js** — HTTP headers hardening\n\n---\n\n## Monitoring & Analytics\n\n### Error Tracking\n- **Sentry** — Crash reporting\n- **LogRocket** — Session replay (frontend)\n\n### Analytics\n- **Google Analytics 4** — User behavior\n- **Segment** — Event tracking\n\n### Performance\n- **Vercel Analytics** — Core Web Vitals\n- **Datadog** or **New Relic** — APM (application monitoring)\n\n### Logs\n- **Winston** or **Pino** — Server logging\n- **CloudWatch** (AWS) or **Papertrail** — Log aggregation\n\n---\n\n## Optional Integrations (Future)\n\n- **Stripe** — Payment processing\n- **SendGrid** — Email delivery at scale\n- **Auth0** — Advanced auth features\n- **Databox** — Analytics dashboard\n- **Zapier** — Workflow automation\n- **Slack** — scanning\n\n---\n\n## Version Numbers (at MVP launch)\n\n| Package | Version |\n|---------|----------|\n| Node.js | 18+ |\n| Next.js | 14+ |\n| React | 18+ |\n| TypeScript | 5+ |\n| Tailwind CSS | 3+
