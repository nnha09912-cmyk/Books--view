images\n- Click to expand lightbox\n- Hover actions (like/star quick buttons)\n- Mobile: 1-2 columns, Desktop: 3-4 columns\n\n#### **Lightbox**\n- Full-screen photo viewer\n- Keyboard navigation (arrow keys)\n- Touch swipe (mobile)\n- Pinch-to-zoom (mobile)\n- Like/Star buttons (bottom)\n- Close button (top)\n- Info bar (current photo index)\n\n#### **ImageCard**\n- Single photo thumbnail\n- Show like/star count\n- Hover state with action buttons\n- Favorite/liked indicator (badge)\n\n### Album\n\n#### **AlbumCard**\n- Summary of album\n- Thumbnail (first photo)\n- Album name, photo count\n- Quick actions: View, Edit, Share, Delete\n- Status badge (active/expired)\n\n#### **AlbumList**\n- Grid or list of AlbumCards\n- Sortable, filterable\n- Pagination\n- Empty state if no albums\n\n#### **AlbumForm**\n- Create/Edit album\n- Step-by-step form\n- Google Drive folder selector\n- Template picker\n- Settings (password, expiry, etc.)\n\n#### **AlbumStats**\n- Total photos, customers, likes, stars\n- Engagement indicators\n- Most liked photos list\n\n### Auth\n\n#### **LoginForm**\n- Email input\n- Password input\n- Forgot password link\n- OAuth buttons (Google, Facebook)\n- Form validation\n\n#### **SignupForm**\n- Name, email, password inputs\n- Studio name input\n- Confirm password\n- Terms acceptance checkbox\n- Form validation\n\n#### **PasswordReset**\n- Email input (request reset)\n- New password inputs (confirm)\n- Validation\n\n### Admin\n\n#### **Dashboard**\n- Welcome card\n- Quick stats (cards)\n- Recent albums (mini list)\n- Activity feed\n- Quick actions\n\n#### **CustomerList**\n- Table of customers\n- Name, email, likes/stars, submitted date\n- Sortable, filterable\n- Row actions (view selections, remove)\n\n#### **SelectionSummary**\n- Card showing liked/starred photos\n- Photo grid (liked photos)\n- Photo grid (starred photos)\n- Download button\n\n#### **AnalyticsChart**\n- Chart.js or Recharts component\n- Likes over time\n- Customer engagement\n- Most liked photos\n\n### Shared\n\n#### **Pagination**\n- Page numbers, prev/next buttons\n- Shows current page/total pages\n- Customizable items per page\n\n#### **SearchBox**\n- Text input with icon\n- Clear button\n- Debounced search\n- Placeholder text\n\n#### **BreadcrumbNav**\n- Hierarchical navigation path\n- Clickable links\n- Responsive (collapses on mobile)\n\n#### **LoadingSpinner**\n- Circular spinner\n- With optional message\n- Full-page overlay option\n\n#### **EmptyState**\n- Large icon\n- Title, description\n- Optional CTA button\n\n### Layout\n\n#### **AdminLayout**\n- Header with logo, title, dark mode toggle\n- Sidebar with navigation\n- Main content area\n- Footer (optional)\n\n#### **GalleryLayout**\n- Header with album name, back button\n- Sidebar (folders, if nested)\n- Main gallery area\n- Footer with instructions\n\n#### **AuthLayout**\n- Centered form container\n- Background image (optional)\n- Logo/branding at top\n- Footer with links\n\n---\n\n## Component Props (TypeScript)\n\n### Button\n```tsx\ninterface ButtonProps {\n  children: React.ReactNode\n function Button({ children, variant = 'primary' }) {\n  const variantClasses = {\n    primary: 'bg-[var(--accent)] text-white hover:bg-[var(--accent-hover)]',\n    secondary: 'border border-[var(--accent)] text-[var(--accent)] hover:bg-[var(--accent)]/10',\n    ghost: 'text-[var(--accent)] hover:bg-[var(--accent)]/10',\n  }\n\n  return (\n    <button className={`px-4 py-2 rounded-md transition-colors ${variantClasses[variant]}`}>\n      {children}\n    </button>\n  )\n}\n```\n\n---\n\n## Component Testing\n\nEach component has:\n- **Unit tests** (Vitest)\n- **Visual
