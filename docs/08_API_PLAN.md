# 08 — API Plan\n\nRESTful API endpoints for Books View backend.\n\n**Base URL:** `https://api.books-view.com/v1`\n\n---\n\n## Authentication\n\n### JWT Token Flow\n```\n1. POST /auth/login → Returns JWT token\n2. Include token in Authorization header: Bearer {token}\n3. Token expires in 7 days (refresh endpoint available)\n```\n\n### API Key (for integrations)\n```\nAuthorization: ApiKey {apiKey}\n```\n\n---\n\n## Endpoints\n\n### Auth\n\n#### `POST /auth/login`\n**Login with email & password**\n```\nRequest:\n{\n  \"email\": \"studio@example.com\",\n  \"password\": \"password123\"\n}\n\nResponse: 200 OK\n{\n  \"token\": \"eyJhbGciOiJIUzI1NiIs...\",\n  \"expiresIn\": 604800,\n  \"studio\": { \"id\", \"name\", \"email\" }\n}\n```\n\n#### `POST /auth/signup`\n**Create new studio account**\n```\nRequest:\n{\n  \"name\": \"Jane Photography\",\n  \"email\": \"jane@example.com\",\n  \"password\": \"password123\",\n  \"studioName\": \"Jane Photography Studios\"\n}\n\nResponse: 201 Created\n{\n  \"token\": \"...\",\n  \"studio\": { ... }\n}\n```\n\n#### `POST /auth/refresh`\n**Refresh JWT token**\n```\nResponse: 200 OK\n{\n  \"token\": \"...\",\n  \"expiresIn\": 604800\n}\n```\n\n#### `POST /auth/logout`\n**Logout (invalidate token)**\n```\nResponse: 200 OK\n{ \"message\": \"Logged out successfully\" }\n```\n\n---\n\n### Albums\n\n#### `GET /albums`\n**List all albums (studio owner)**\n```\nQuery params:\n- page: 1\n- limit: 20\n- status: active|archived|expired\n- sort: -createdAt (default), name, photoCount\n- search: \"album name\"\n\nResponse: 200 OK\n{\n  \"data\": [\n    {\n      \"id\": \"album-uuid\",\n      \"name\": \"John & Jane's Wedding\",\n      \"description\": \"...\",\n      \"template\": \"wedding\",\n      \"photoCount\": 250,\n      \"customerCount\": 2,\n      \"status\": \"active\",\n      \"linkToken\": \"abc123xyz\",\n      \"createdAt\": \"2024-01-15T10:00:00Z\"\n    }\n  ],\n  \"pagination\": {\n    \"page\": 1,\n    \"limit\": 20,\n    \"total\": 45,\n    \"pages\": 3\n  }\n}\n```\n\n#### `POST /albums`\n**Create new album**\n```\nRequest:\n{\n  \"name\": \"Wedding Album\",\n  \"description\": \"John & Jane's wedding\",\n  \"template\": \"wedding\",\n  \"googleDriveFolderId\": \"folder-id-from-drive\", // OR\n  \"uploadFiles\": [file1, file2, ...] // File upload\n  \"password\": \"1234\", // Optional\n  \"expiryDate\": \"2024-02-15\"\n}\n\nResponse: 201 Created\n{\n  \"id\": \"album-uuid\",\n  \"linkToken\": \"abc123xyz\",\n  \"shareUrl\": \"https://books-view.com/album/abc123xyz\",\n  ...\n}\n```\n\n#### `GET /albums/:albumId`\n**Get album details**\n```\nResponse: 200 OK\n{\n  \"id\": \"album-uuid\",\n  \"name\": \"Wedding Album\",\n  \"description\": \"...\",\n  \"template\": \"wedding\",\n  \"photoCount\": 250,\n  \"customerCount\": 2,\n  \"status\": \"active\",\n  \"linkToken\": \"abc123xyz\",\n  \"shareUrl\": \"https://books-view.com/album/abc123xyz\",\n  \"createdAt\": \"2024-01-15T10:00:00Z\",\n  \"updatedAt\": \"2024-01-16T10:00:00Z\"\n}\n```\n\n#### `PATCH /albums/:albumId`\n**Update album**\n```\nRequest: (partial)\n{\n  \"name\": \"New name\",\n  \"description\": \"New description\",\n  \"template\": \"classic\"\n}\n\nResponse: 200 OK\n{ ... updated album ... }\n```\n\n#### `DELETE /albums/:albumId`\n**Delete album (soft delete)**\n```\nResponse: 204 No Content\n```\n\n#### `POST /albums/:albumId/archive`\n**Archive album**\n```\nResponse: 200 OK\n{ \"status\": \"archived\" }\n```\n\n---\n\n### Photos\n\n#### `GET /albums/:albumId/photos`\n**List photos in album**\n```\nQuery params:\n- folderId: (optional, filter by folder)\n- page: 1\n- limit: 50\n\nResponse: 200 OK\n{\n  \"data\": [\n    {\n      \"id\": \"photo-uuid\",\n      \"filename\": \"photo-001.jpg\",\n      \"thumbnailUrl\": \"https://...\",\n      \"previewUrl\": \"https://...\",\n      \"originalUrl\": \"https://...\",\n      \"width\": 4000,\n      \"height\": 3000,\n      \"likeCount\": 5,\n      \"starCount\": 2\n    }\n  ],\n  \"pagination\": { ... }\n}\n```\n\n#### `POST /albums/:albumId/photos`\n**Add photos to album** (manual upload or Drive sync)\n```\nRequest:\n{\n  \"googleDriveFolderId\": \"folder-id\" // OR upload files\n}\n\nResponse: 201 Created\n{\n  \"photosAdded\": 15,\n  \"photos\": [ ... ]\n}\n```\n\n#### `DELETE /albums/:albumId/photos/:photoId`\n**Remove photo**\n```\nResponse: 204 No Content\n```\n\n---\n\n### Folders\n\n#### `GET /albums/:albumId/folders`\n**List folders in album**\n```\nResponse: 200 OK\n{\n  \"data\": [\n    {\n      \"id\": \"folder-uuid\",\n      \"name\": \"Getting Ready\",\n      \"photoCount\": 50,\n      \"parentFolderId\": null\n    }\n  ]\n}\n```\n\n#### `POST /albums/:albumId/folders`\n**Create folder**\n```\nRequest:\n{\n  \"name\": \"Reception\",\n  \"parentFolderId\": \"parent-folder-id\" // Optional\n}\n\nResponse: 201 Created\n{ ... folder ... }\n```\n\n---\n\n### Customers (Album Viewers)\n\n#### `GET /albums/:albumId/customers`\n**List customers & their selections**\n```\nResponse: 200 OK\n{\n  \"data\": [\n    {\n      \"id\": \"customer-uuid\",\n      \"name\": \"John Doe\",\n      \"email\": \"john@example.com\",\n      \"likes\": 45,\n      \"stars\": 12,\n      \"submittedAt\": \"2024-01-16T10:00:00Z\",\n      \"lastViewedAt\": \"2024-01-16T10:00:00Z\"\n    }\n  ]\n}\n```\n\n#### `POST /albums/:albumId/customers`\n**Add/invite customer**\n```\nRequest:\n{\n  \"name\": \"John Doe\",\n  \"email\": \"john@example.com\",\n  \"phone\": \"+1-555-0000\" // Optional\n}\n\nResponse: 201 Created\n{\n  \"customer\": { ... },\n  \"shareLink\": \"https://books-view.com/album/abc123xyz\"\n}\n```\n\n#### `GET /albums/:albumId/customers/:customerId/selections`\n**Get customer's selections**\n```\nResponse: 200 OK\n{\n  \"liked\": [\n    { \"photoId\": \"...\", \"filename\": \"photo-001.jpg\", ... }\n  ],\n  \"starred\": [\n    { \"photoId\": \"...\", \"filename\": \"photo-002.jpg\", ... }\n  ]\n}\n```\n\n---\n\n### Public Gallery API (No Auth Required)\n\n#### `GET /public/album/:linkToken`\n**Get album info (public)**\n```\nResponse: 200 OK\n{\n  \"name\": \"Wedding Album\",\n  \"description\": \"...\",\n  \"template\": \"wedding\",\n  \"photoCount\": 250,\n  \"requiresPassword\": true // or false\n}\n```\n\n#### `POST /public/album/:linkToken/auth`\n**Authenticate with password (if required)**\n```\nRequest:\n{\n  \"password\": \"1234\"\n}\n\nResponse: 200 OK\n{\n  \"token\": \"guest-token-xyz\",\n  \"expiresIn\": 86400\n}\n```\n\n#### `GET /public/album/:linkToken/photos`\n**Get photos (requires guest token if password protected)**\n```\nHeaders:\nAuthorization: Bearer {guestToken}\n\nQuery params:\n- folderId: (optional)\n- page: 1\n- limit: 50\n\nResponse: 200 OK\n{\n  \"data\": [\n    { \"id\", \"filename\", \"thumbnailUrl\", \"previewUrl\", ... }\n  ],\n  \"pagination\": { ... }\n}\n```\n\n#### `GET /public/album/:linkToken/folders`\n**Get folder structure**\n```\nResponse: 200 OK\n{\n  \"data\": [\n    { \"id\", \"name\", \"photoCount\", \"parentFolderId\" }\n  ]\n}\n```\n\n#### `POST /public/album/:linkToken/customers`\n**Create customer session**\n```\nRequest:\n{\n  \"name\": \"John Doe\",\n  \"email\": \"john@example.com\" // Optional\n}\n\nResponse: 201 Created\n{\n  \"customerId\": \"customer-uuid\",\n  \"guestToken\": \"...\"\n}\n```\n\n#### `POST /public/album/:linkToken/selections`\n**Submit photo selection (like/star)**\n```\nHeaders:\nAuthorization: Bearer {guestToken}\n\nRequest:\n{\n  \"photoId\": \"photo-uuid\",\n  \"type\": \"like\" // or \"star\"\n}\n\nResponse: 201 Created | 204 No Content (if already liked)\n{ \"success\": true }\n```\n\n#### `DELETE /public/album/:linkToken/selections/:photoId`\n**Remove selection (unlike/unstar)**\n```\nHeaders:\nAuthorization: Bearer {guestToken}\n\nResponse: 204 No Content\n```\n\n#### `POST /public/album/:linkToken/submit`\n**Finalize customer selections**\n```\nHeaders:\nAuthorization: Bearer {guestToken}\n\nResponse: 200 OK\n{\n  \"message\": \"Selections submitted\",\n  \"liked\": 45,\n  \"starred\": 12\n}\n```\n\n---\n\n### Analytics\n\n#### `GET /albums/:albumId/analytics`\n**Album analytics**\n```\nResponse: 200 OK\n{\n  \"totalPhotos\": 250,\n  \"totalLikes\": 120,\n  \"totalStars\": 45,\n  \"customerCount\": 2,\n  \"viewCount\": 15,\n  \"averageLikesPerPhoto\": 0.48,\n  \"mostLikedPhotos\": [\n    { \"photoId\", \"filename\", \"likeCount\": 5 }\n  ],\n  \"timelineData\": [\n    { \"date\": \"2024-01-15\", \"likes\": 30, \"views\": 5 }\n  ]\n}\n```\n\n---\n\n### Export\n\n#### `GET /albums/:albumId/export/csv`\n**Export selections as CSV**\n```\nQuery params:\n- includePhotos: true|false (download image URLs)\n\nResponse: 200 OK (CSV file download)\n```\n\n#### `GET /albums/:albumId/export/json`\n**Export all data as JSON**\n```\nResponse: 200 OK (JSON file download)\n```\n\n---\n\n## Error Handling\n\n### Standard Error Response\n```json\n{\n  \"error\": {\n    \"code\": \"ALBUM_NOT_FOUND\",\n    \"message\": \"Album with ID abc123 not found\",\n    \"status\": 404,\n    \"timestamp\": \"2024-01-16T10:00:00Z\"\n  }\n}\n```\n\n### Common Status Codes\n- `200 OK` — Success\n- `201 Created` — Resource created\n- `204 No Content` — Success, no response body\n- `400 Bad Request` — Invalid input\n- `401 Unauthorized` — Missing/invalid auth\n- `403 Forbidden` — No permission\n- `404 Not Found` — Resource not found\n- `409 Conflict` — Duplicate resource\n- `429 Too Many Requests` — Rate limit exceeded\n- `500 Internal Server Error` — Server error\n\n---\n\n## Rate Limiting\n\n- **Per studio:** 1000 requests/hour\n- **Per public link:** 100 requests/minute (to prevent abuse)\n- **Rate limit headers:**\n  - `X-RateLimit-Limit: 1000`\n  - `X-RateLimit-Remaining: 999`\n  - `X-RateLimit-Reset: 1705400000`\n\n---\n\n## Pagination\n\nAll list endpoints support:\n- `page` — Page number (default 1)\n- `limit` — Items per page (default 20, max 100)\n- `sort` — Sort field (prefix with `-` for descending)\n\nResponse includes:\n```json\n{\n  \"data\": [...],\n  \"pagination\": {\n    \"page\": 1,\n    \"limit\": 20,\n    \"total\": 150,\n    \"pages\": 8\n  }\n}\n```\n
