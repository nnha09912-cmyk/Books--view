# 06 — Sitemap\n\nComplete page structure and navigation hierarchy for Books View.\n\n---\n\n## Admin (Studio) Pages\n\n### 1. **Auth Pages**\n\n#### `/auth/login`\n- Email input\n- Password input\n- \"Forgot password?\" link\n- \"Login\" button\n- \"Sign up\" link\n- OAuth options (Google, Facebook)\n\n#### `/auth/signup`\n- Name input\n- Email input\n- Password input (confirm)\n- Studio name input\n- Phone number (optional)\n- \"Create account\" button\n- \"Already have account?\" link\n\n#### `/auth/forgot-password`\n- Email input\n- \"Send reset link\" button\n- Back to login link\n\n#### `/auth/reset-password`\n- New password input\n- Confirm password input\n- \"Reset password\" button\n\n#### `/auth/2fa`\n- 2FA code input (6 digits)\n- \"Verify\" button\n- \"Resend code\" link\n\n---\n\n### 2. **Dashboard**\n\n#### `/dashboard`\n- Header: Studio name, dark mode toggle, settings, logout\n- Sidebar: Dashboard, Albums, Settings\n- Main area:\n  - Welcome card (studio stats)\n  - Quick stats: Total albums, total photos, total customers, total likes/stars\n  - Recent albums (cards)\n  - Activity feed (latest selections)\n  - CTA: \"Create Album\" button\n\n---\n\n### 3. **Albums**\n\n#### `/albums`\n- Header: \"My Albums\"\n- Sidebar nav\n- Toolbar:\n  - Search by album name\n  - Filter by status (active, archived, expired)\n  - Sort by (date, views, likes)\n  - \"Create Album\" button\n- Album cards (grid):\n  - Thumbnail (first photo)\n  - Album name\n  - Photo count\n  - Customer count\n  - Date created\n  - Status (active/expired)\n  - Actions: View, Edit, Share, Delete\n\n#### `/albums/create`\n- Step 1: Upload source\n  - Option A: Link to Google Drive folder\n  - Option B: Upload files\n  - Show folder preview\n- Step 2: Album details\n  - Album name (required)\n  - Album description (optional)\n  - Customer name (optional, filled later)\n- Step 3: Configuration\n  - Choose template (Classic, Wedding, etc.)\n  - Password protection (toggle + input)\n  - Expiry date (optional)\n  - Responsive settings (if any)\n- Step 4: Review & confirm\n  - Preview album in chosen template\n  - \"Create album\" button\n\n#### `/albums/[id]` (Album Dashboard)\n- Header: Album name, back button\n- Tabs: Overview, Gallery, Analytics, Settings, Export\n\n**Tab: Overview**\n- Album info: name, description, template, status\n- Quick actions: Edit, Share, Delete\n- Customer list (if added)\n- Share link section:\n  - Unique link (copyable)\n  - QR code\n  - Email invite button\n  - SMS invite button\n\n**Tab: Gallery**\n- Grid view of all photos\n- Click to expand lightbox preview\n- Show which photos are liked/starred (badges)\n- Upload additional photos (if from Drive)\n- Reorder photos (drag-drop)\n\n**Tab: Analytics**\n- Chart: Likes vs stars over time\n- Customer list with their selections:\n  - Customer name\n  - Liked count\n  - Starred count\n  - Viewed date\n  - Last updated\n  - View selections (expand)\n- Export button (CSV, JSON)\n\n**Tab: Settings**\n- Edit album name/description\n- Change template\n- Password/PIN settings\n- Expiry date\n- Archive/Delete button\n\n**Tab: Export**\n- Download options:\n  - \"All liked photos (list)\"\n  - \"All starred photos (list)\"\n  - \"Analytics (CSV)\"\n  - \"Customer selections (JSON)\"\n- Batch download photos (if enabled)\n\n#### `/albums/[id]/edit`\n- Form to update album details\n- Same fields as create\n- \"Save changes\" button\n\n#### `/albums/[id]/share`\n- Copy link to clipboard\n- Email invite form (customer email)\n- SMS invite (customer phone)\n- Generate QR code\n- Social share (if enabled)\n\n---\n\n### 4. **Settings**\n\n#### `/settings`\n- Sidebar: Profile, Billing, API, Notifications\n\n**Profile:**\n- Name, email, phone\n- Studio name, logo\n- Bio/description\n- Password change\n- 2FA toggle\n- Session management (logout all devices)\n\n**Billing:**\n- Current plan\n- Usage stats (storage, API calls)\n- Billing history\n- Payment method\n- Invoice download\n\n**API:**\n- API keys management\n- API documentation link\n- Webhook settings\n\n**Notifications:**\n- Email notifications toggle\n- SMS notifications toggle\n- Frequency (immediate, daily digest)\n- Customer submitted selections (toggle)\n\n---\n\n## Public Pages (Customer)\n\n### `/album/[linkId]` (Album Landing)\n- Header: Studio logo/name, dark mode toggle\n- Hero section:\n  - Album name\n  - Description (if set)\n  - Folder structure (if nested)\n  - \"Start Viewing\" CTA\n- Footer: Studio contact info\n\n### `/album/[linkId]/gallery` (Gallery View)\n- Header: Album name, progress (10/300 photos), back button\n- Toolbar:\n  - Search by photo name (if tagged)\n  - View toggle (grid/carousel)\n  - Selection summary (X liked, Y starred)\n  - Instructions badge\n- Main gallery:\n  - Grid: 2 cols (mobile), 3-4 cols (desktop)\n  - Lazy load images\n  - Hover/tap: like/star quick actions\n  - Click to fullscreen lightbox\n\n### `/album/[linkId]/gallery/[photoId]` (Lightbox)\n- Full screen image\n- Info bar: Photo X/total\n- Navigation: Arrows (left/right), keyboard arrows\n- Actions (bottom): Like (♥), Star (⭐)\n- Close: (X) button (top)\n- Swipe: Next/prev on mobile\n- Zoom: Pinch-to-zoom on mobile\n\n### `/album/[linkId]/confirm` (Confirmation)\n- Thank you message\n- Summary:\n  - Liked: 45 photos\n  - Starred: 20 photos\n- \"Back to gallery\" or \"View liked photos\" button\n- Studio contact info\n- Option: \"Email me the album link\"\n\n---\n\n## Navigation Structure\n\n```\nBooks View (Root)\n├── Auth\n│   ├── Login\n│   ├── Signup\n│   ├── Forgot Password\n│   └── Reset Password\n├── Admin\n│   ├── Dashboard\n│   ├── Albums\n│   │   ├── List\n│   │   ├── Create\n│   │   ├── [id]\n│   │   │   ├── Overview\n│   │   │   ├── Gallery\n│   │   │   ├── Analytics\n│   │   │   ├── Settings\n│   │   │   └── Export\n│   │   ├── [id]/Edit\n│   │   └── [id]/Share\n│   └── Settings\n│       ├── Profile\n│       ├── Billing\n│       ├── API\n│       └── Notifications\n└── Public\n    └── Album\n        ├── [linkId] (Landing)\n        ├── [linkId]/Gallery\n        ├── [linkId]/Gallery/[photoId]\n        └── [linkId]/Confirm\n```\n\n---\n\n## URL Patterns\n\n### Admin Routes\n```\n/dashboard\n/albums\n/albums/create\n/albums/[albumId]\n/albums/[albumId]/edit\n/albums/[albumId]/share\n/settings\n/settings/profile\n/settings/billing\n/settings/api\n```\n\n### Public Routes\n```\n/album/[linkId]\n/album/[linkId]/gallery\n/album/[linkId]/gallery/[photoId]\n/album/[linkId]/confirm\n```\n\n---\n\n## Breadcrumb Navigation\n\n### Admin\n```\nDashboard\nDashboard > Albums\nDashboard > Albums > Create\nDashboard > Albums > [Album Name] > Overview\nDashboard > Albums > [Album Name] > Gallery\nDashboard > Settings > Profile\n```\n\n### Public (Customer)\n```\nHome (studio logo click)\n[Album Name]\n[Album Name] > Confirm\n```\n\n---\n\n## Not Included (Out of Scope MVP)\n\n- ❌ Blog/documentation pages\n- ❌ Pricing page\n- ❌ FAQ page\n- ❌ Support/help center\n- ❌ Terms/Privacy (reference only)\n- ❌ Account deletion flow\n- ❌ Admin user management (multi-user)\n- ❌ Template builder/customization\n
