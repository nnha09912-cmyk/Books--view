# 05 — User Flow\n\n## Two Main Actors\n\n1. **Studio** (Admin) — Photographer/studio owner\n2. **Customer** (End-user) — Khách hàng xem ảnh\n\n---\n\n## Studio Admin Flow\n\n```\n┌─────────────────────────┐\n│  Studio (Admin) Login   │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│   Dashboard             │\n│ (All albums & stats)    │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  Create New Album       │\n│ (Link to Google Drive)  │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  Select Folder/Files    │\n│  Choose Template        │\n│  Add Title & Details    │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  Generate Link          │\n│ (Unique per album)      │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  Share Link to Customer │\n│ (Copy/Email/SMS)        │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  View Album Analytics   │\n│ - Photos liked/starred  │\n│ - Customer insights     │\n│ - Export selections     │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│  Export for Production  │\n│ - Download liked list   │\n│ - Start retouch/print   │\n└──────────┬──────────────┘\n           ↓\n┌─────────────────────────┐\n│   Done                  │\n└─────────────────────────┘\n```\n\n### Steps Detail\n\n**1. Login**\n- Email + password (or Google OAuth)\n- 2FA optional\n- Remember me option\n\n**2. Dashboard**\n- List of all albums (cards)\n- Quick stats: total albums, total customers, liked/starred count\n- Search/filter albums by date\n- \"Create Album\" button\n\n**3. Create Album**\n- Option A: Link to Google Drive folder\n- Option B: Upload files manually\n- Show folder structure preview\n\n**4. Configure Album**\n- Album name\n- Album description (optional)\n- Choose template (Classic, Wedding, etc.)\n- Set password protection (optional)\n- Set expiry date (optional)\n\n**5. Generate Link**\n- Unique link: `books-view.com/album/abc123xyz`\n- QR code option\n- Link settings: copy, email, export\n\n**6. View Analytics**\n- List of customers invited\n- Which photos they liked/starred\n- Engagement timeline\n- Export selections as CSV/JSON\n\n**7. Export**\n- Download list of liked photos (JSON/CSV)\n- Download starred photos (batch or one-by-one)\n\n---\n\n## Customer (End-user) Flow\n\n```\n┌──────────────────────────┐\n│  Customer Receives Link  │\n│ (Email/SMS/QR Code)      │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Click/Open Link         │\n│  Landing Page            │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Enter Album (optional   │\n│  password if set)        │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  View Album Info         │\n│ (Name, description,      │\n│  folder structure)       │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Browse Gallery Grid     │\n│ (Lazy load, responsive)  │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Click Photo             │\n│  Open Full Lightbox      │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  View Full Size Image    │\n│ (Swipe, zoom, keyboard)  │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  React: Like (♥) or      │\n│  Star (⭐)               │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Continue Browsing       │\n│ (Next/prev or grid)      │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Submit Selections       │\n│ (Save likes/stars)       │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Confirmation Page       │\n│ - Thank you message      │\n│ - Summary of choices     │\n└──────────┬───────────────┘\n           ↓\n┌──────────────────────────┐\n│  Done                    │\n│ (Can revisit link later) │\n└──────────────────────────┘\n```\n\n### Steps Detail\n\n**1. Receive Link**\n- Email: \"Check out your photos!\"\n- SMS: Short link (bitly/qr)\n- WhatsApp: Click-friendly\n\n**2. Landing Page**\n- Hero section (album name, studio logo)\n- Brief instructions\n- \"Start Viewing\" button\n- Studio contact info (footer)\n\n**3. Authentication** (if needed)\n- If password set: password input\n- If pin: 4-digit code\n- Persistence: localStorage (stay logged in 7 days)\n\n**4. Album Overview**\n- Album title + description\n- Folder structure (if nested)\n- Thumbnail preview of first 3 photos\n- Total count: \"200+ photos\"\n- Instructions: \"Like (♥) to print, Star (⭐) to download\"\n\n**5. Gallery Grid**\n- 2 columns (mobile), 3-4 (desktop)\n- Lazy load: skeleton placeholder\n- Click to expand lightbox\n- Tap to select/like/star (quick action on hover)\n\n**6. Full Lightbox**\n- Full screen\n- Left/right arrows or swipe\n- Keyboard arrows for navigation\n- Pinch-to-zoom (mobile)\n- Info bar: \"Photo 42/200\"\n- Like/star buttons (bottom)\n- Close button (top)\n\n**7. React/Interact**\n- Click like (♥) → heart fills red, confirms\n- Click star (⭐) → star fills gold, confirms\n- Toast confirmation: \"Added to likes!\"\n- Can unlike/unstar by clicking again\n\n**8. Continue**\n- Arrow keys or on-screen buttons\n- Swipe (mobile)\n- Click back to grid\n\n**9. Submit**\n- Button to finalize selections\n- Confirmation: \"Your selections saved!\"\n- Option to continue browsing\n\n**10. Confirmation**\n- Thank you message\n- Summary: \"You liked 45 photos, starred 20\"\n- Studio contact: \"We'll be in touch!\"\n- Option to revisit\n\n---\n\n## Happy Paths (Ideal Scenarios)\n\n### Admin Happy Path\n1. Admin uploads album to Drive (300 photos)\n2. Creates album in Books View (2 mins)\n3. Shares link to customer\n4. Customer browses & selects\n5. Admin views analytics → likes 50 photos for printing\n6. Admin exports CSV → sends to retouch team\n7. Done ✅\n\n**Time:** 5 mins admin, 10 mins customer\n\n### Customer Happy Path\n1. Opens link from email\n2. Sees beautiful album in chosen template\n3. Scrolls through, likes favorite photos\n4. Stars a few personal favorites\n5. Submits selections\n6. Sees confirmation\n7. Done ✅\n\n**Time:** 10-15 mins\n\n---\n\n## Edge Cases\n\n### Admin Edge Cases\n- **Album with 1000+ photos** → Pagination, lazy load\n- **Slow internet** → Show loading states, allow offline scroll (cached)\n- **Large files** → Resize/compress on upload\n- **Password-protected** → Customer needs PIN to access\n- **Expiry date set** → Album auto-disables after date\n\n### Customer Edge Cases\n- **Closes browser mid-browsing** → Resume where left off (localStorage)\n- **No internet** → Show cached photos, queue selections (sync when online)\n- **Accidentally liked/starred** → Can unlike by clicking again\n- **Changes mind** → Can unsubmit before final confirmation\n- **Mobile, small screen** → Single column, large touch targets\n- **Zoom on image** → Pinch-to-zoom works smoothly\n\n---\n\n## Decision Points\n\n### Do customers need an account?\n- **MVP:** No account needed (link-based access)\n- **Future:** Optional email registration for repeat access\n\n### Can customers modify selections later?\n- **MVP:** Yes, until they submit\n- **Future:** Can re-open link 7 days after first view\n\n### Do customers see other customers' selections?\n- **No** (privacy) — Each customer sees only their own\n\n### Can admin delete selections?\n- **Yes** — Admin can remove/edit customer selections\n- **Future:** Approval workflow (customer submits → admin approves)\n
