# Books View — Project Summary\n\n**Status:** ✅ Phase 0 Complete (Documentation)\n\n---\n\n## What is Books View?\n\n📸 **Photo Gallery & Selection Platform for Photography Studios**\n\nA web app where:\n- Studios upload photo albums from Google Drive\n- Customers browse beautiful gallery and pick favorite photos\n- Customers mark photos as \"Like\" (♥ for printing) or \"Star\" (⭐ for personal use)\n- Studios see which photos customers selected, download list for production\n\n---\n\n## Key Info\n\n| Aspect | Details |\n|--------|----------|\n| **Product** | Books View |\n| **Client** | Photography studios (B2B) |\n| **Users** | Studio owners + customers |\n| **MVP Timeline** | 12 weeks (3 months) |\n| **Tech Stack** | Next.js, React, TypeScript, Tailwind, PostgreSQL, Prisma |\n| **Key Principle** | Performance First, Image First, Mobile First |\n\n---\n\n## Documentation (15 Files)\n\n```\n00_PROJECT_VISION.md          ← Start here (what + why)\n01_PRODUCT_GUIDELINE.md       ← Design philosophy\n02_UI_UX_GUIDELINE.md         ← Design rules\n03_DESIGN_SYSTEM.md           ← Components\n04_TEMPLATE_SYSTEM.md         ← Themes (classic, wedding, etc.)\n05_USER_FLOW.md               ← How users interact\n06_SITEMAP.md                 ← Page structure\n07_DATABASE_PLAN.md           ← Schema & tables\n08_API_PLAN.md                ← REST endpoints\n09_TECH_STACK.md              ← Technologies\n10_SECURITY.md                ← Auth, encryption, etc.\n11_COMPONENT_SYSTEM.md        ← Reusable components\n12_ROADMAP.md                 ← 5 phases, 12 weeks\n13_PROJECT_RULES.md           ← Critical rules (MUST READ)\n14_CLAUDE.md                  ← How Claude works here\nREADME.md                      ← Quick start guide\n```\n\n**All in:** `/docs/`\n\n---\n\n## Critical Rules (Never Forget!)\n\n🚫 **NEVER:**\n1.
